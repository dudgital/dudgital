# Naming

| Name | Role |
|------|------|
| **Dudgital** | Product — Developer Automation Platform |
| **`@dudgital/*`** | Public npm scope |
| **`@dudgital/dude`** | CLI package |
| **`dude` / `dg`** | CLI binaries (`dg` = everyday short form) |
| **Lumiarq** | Legacy meta-framework effort — frozen for Dudgital product work |
| **Lumis** | Legacy Lumiarq CLI — not the Dudgital CLI |
| **Traze** | Observability; pattern seed for dashboard only |

Do not ship Dudgital under `@lumiarq`. Do not brand the automation CLI as Lumis.
